# GameOn — offline app

**Android:** transfer `GameOn.apk` to your Android phone and open it to install. The phone may ask you to approve installation from the file manager. This is a development-signed prototype, not a Play Store release.

**HTML:** open `GameOn App.html` directly in a modern browser. Images, fonts and code are included inside the file. No server or internet connection is needed.

Use it to explore experiences, save favourites, shortlist café items, plan a session with a budget, share the idea and run a session timer. Use **Club** to change the theme or find the venue details.

Saved plans are not reservations. Café shortlists are not orders. Confirm availability and final prices with the club. There is no backend, account, payment flow, Internet permission, tracking or background alarm.

Data stays in that installation/browser’s local storage. The Android app and the browser HTML keep separate data. Uninstalling the app or clearing browser storage removes it.

Signature and alignment checks passed. Local interaction tests passed. Physical Android installation and visual device testing have not been performed.

Source and rebuild instructions: `mobile/README.md`.
