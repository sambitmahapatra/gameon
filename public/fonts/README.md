# Bundled website fonts

These are the unmodified Latin WOFF2 variable-font subsets previously served by `next/font/google`: Bricolage Grotesque, Instrument Sans and JetBrains Mono. They are now loaded through `next/font/local`, so production builds do not depend on Google Fonts requests or the Next.js Google CSS parser.

Each family has its corresponding SIL Open Font License alongside the font file. Upstream licenses and source fonts are maintained in [Google Fonts](https://github.com/google/fonts/tree/main/ofl).
