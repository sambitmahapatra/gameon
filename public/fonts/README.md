# Bundled website fonts

The social club redesign uses Barlow Condensed (800 and 900) and the DM Sans variable font, downloaded unmodified from Google's official font repository. JetBrains Mono remains available for technical labels. Fonts are loaded through `next/font/local`, so production builds do not depend on external font requests.

The earlier Bricolage Grotesque and Instrument Sans Latin WOFF2 subsets are retained as previous design assets.

Each family has its corresponding SIL Open Font License alongside the font file. Upstream licenses and source fonts are maintained in [Google Fonts](https://github.com/google/fonts/tree/main/ofl).
